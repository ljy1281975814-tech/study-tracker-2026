# 回归预检（preflight）

把「照抄必过 / 漏整句不给过 / 看答案不能回填 / 空答不记账 / 单选单记 / 三态不穿透 / SE 不双记 / 练习零写库 / PO 累计不被作用域打死 / 门不裁剪」这些硬约束固化成可复跑断言。

**目的**：避免「改 A 坏 B」与「声称修但没生效」——这两个问题在本项目历史上共出现 **20 次**（其中 3 次是同一类：补丁引用到不存在的作用域变量，把已修好的 P0 又打回去）。

## 用法

```bash
# 1. 起本地静态服务（必须 http，不能 file://）
python -m http.server 18080 --bind 127.0.0.1

# 2. 跑预检（无第三方依赖，用本机 Edge --headless + 纯 CDP）
node _tools/preflight.mjs
# 可选：--url http://127.0.0.1:18080   --edge "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
```

退出码：`0` 全过；`1` 有失败；`2` 预检自身异常。

## DOM 级断言（J/K/L）

- **J**：文本照抄 → 三态「熟知」→ `days.c` 必须 +1（钉死「文本熟知不进 days.c」P1）
- **K**：完成页统计卡结构可读（不变量 `answered = right + wrong + selfJudged + partial + learned` 的落点）
- **L**：`PO-DAYS` 距考试天数与 `MOTIV D-N` 同源（钉死 00:00–04:00 两套倒计时）

## 设计原则

1. **断言 store 状态，不只看 UI 文本** —— UI 可能被 render 覆盖（SE box 文案就吃过这个亏）。
2. **每条断言独立 label** —— 失败时打印实测值，便于定位。
3. **只读，不写部署文件** —— 可在评审冻结窗口内跑。
4. **零依赖** —— 不假设评审环境装了 Playwright。
